# Contributing

Bug reports and pull requests are welcome.

1. Fork the repo and branch from `main`.
2. Follow [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/wordpress-coding-standards/).
3. Run `php -l` on every changed file.
4. Open a PR against `main` with a clear description.

By contributing you agree your code will be licensed under GPL-2.0-or-later.
