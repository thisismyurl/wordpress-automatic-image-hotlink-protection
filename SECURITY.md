# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 26.05.x | ✅ Yes |
| < 26.05 | ❌ No |

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/thisismyurl/wordpress-automatic-image-hotlink-protection/security/advisories/new) or email **security@thisismyurl.com**.

You will receive a response within 72 hours.
